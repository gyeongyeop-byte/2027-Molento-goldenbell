# 실시간 골든벨

QR 찍고 → 휴대폰으로 접속 → 실시간 객관식 서바이벌. 정답자는 통과, 오답자·미제출자는 탈락. 마지막까지 남은 사람이 골든벨을 울립니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 참가자 | `/` | 휴대폰 (QR로 접속) |
| 무대 화면 | `/screen` | 빔프로젝터·TV (QR, 문제, 타이머, 결과) |
| 관리자 | `/admin` | 진행자 (노트북 또는 휴대폰) |

관리자 비밀번호 기본값은 **goldenbell** 입니다. 실제로 쓸 때는 꼭 바꾸세요 (아래 참고).

---

## 방법 1. 인터넷에 올려서 쓰기 (추천 · 노트북 서버 불필요)

[Render](https://render.com) 무료 플랜으로 `https://….onrender.com` 주소를 받아 쓰는 방법입니다. 참가자는 와이파이·LTE 상관없이 접속됩니다.

1. [GitHub](https://github.com)에 새 저장소를 만들고 이 폴더의 파일을 전부 올립니다 (웹에서 "Add file → Upload files"로 끌어다 놓으면 됩니다).
2. Render 가입 → **New → Blueprint** → 방금 만든 저장소 선택 (폴더에 든 `render.yaml`을 자동으로 읽습니다).
3. `ADMIN_PASSWORD` 값을 물어보면 원하는 관리자 비밀번호를 넣고 **Apply**.
4. 몇 분 뒤 나오는 주소로 접속하면 끝. QR에는 그 주소가 자동으로 들어갑니다.

무료 플랜 주의점
- 15분 동안 아무도 접속하지 않으면 잠들고, 다시 깨어나는 데 30초~1분 걸립니다. **행사 시작 10분 전에 무대 화면을 미리 열어 두세요.**
- 서버가 재시작되면 관리자 화면에서 수정한 문제가 처음 올린 `questions.json`으로 돌아갑니다. 문제를 다 만든 뒤 관리자 → 문제 편집 → "텍스트로 한 번에 입력 → 현재 문제 불러오기"로 내용을 복사해 두거나, 최종 문제를 `questions.json`에 넣어 GitHub에 다시 올려 두면 안전합니다.

## 방법 2. 노트북에서 직접 실행

1. [Node.js](https://nodejs.org) LTS 버전 설치
2. 이 폴더에서 터미널(명령 프롬프트)을 열고:
   ```
   npm install
   npm start
   ```
3. 터미널에 참가자·무대·관리자 주소가 표시됩니다.
4. 비밀번호 바꾸기: `ADMIN_PASSWORD=원하는비번 npm start`
   (Windows PowerShell: `$env:ADMIN_PASSWORD="원하는비번"; npm start`)

이 경우 참가자 휴대폰이 접속하려면:
- **같은 와이파이**: 노트북과 휴대폰이 같은 와이파이면 바로 됩니다. 단, 휴대폰 핫스팟은 보통 10명 안팎까지만 붙고, 일부 숙소·공용 와이파이는 기기끼리 통신을 막아 둡니다.
- **LTE로도 접속**: [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) 설치 후 터미널을 하나 더 열어 `cloudflared tunnel --url http://localhost:3000` 실행 → 나오는 `https://….trycloudflare.com` 주소를 관리자 → **설정 → QR 코드 주소**에 넣고 적용.

## 진행 순서

1. 관리자 → **설정**에서 행사 이름 입력 (예: "2026 신입생 MT 골든벨")
2. 관리자 → **문제 편집**에서 문제 준비 (들어 있는 8문제는 `[예시]`입니다)
3. 무대 화면(`/screen`)을 빔프로젝터에 띄움 → 참가자들이 QR로 입장, 이름이 화면에 뜸
4. 무대 화면 오른쪽 아래 **소리 켜기**를 한 번 눌러 두면 카운트다운·정답·골든벨 효과음이 나옵니다.
5. 관리자 → **진행** 탭
   - **1번 문제 시작** → 타이머가 끝나면 자동 마감 (또는 **지금 마감**, **+10초**)
   - **정답 공개** → 오답자·미제출자 자동 탈락, 보기별 인원이 무대에 표시, 휴대폰에 "통과!" / "탈락"
   - **다음 문제 시작** 반복
   - 전원 탈락하면: **이번 탈락자 부활** 또는 **전원 부활** (패자부활)
   - 마지막에 **게임 종료 · 우승 발표** → 생존자 이름이 무대에 크게 표시
6. 관리자 화면에서는 진행 중에도 보기별 제출 인원과 정답이 실시간으로 보입니다. 무대·참가자에게는 공개 전까지 숨겨집니다.

## 관리자 기능

- **진행**: 문제 시작·마감·시간 추가·정답 공개·다음 문제, 원하는 번호의 문제로 바로 이동, 무대·참가자 화면에 공지 띄우기
- **참가자**: 접속 상태, 이번 답, 맞힌 수 확인 · 개별 부활/탈락 처리/퇴장 · 이번 탈락자 또는 전원 부활
- **문제 편집**: 질문·보기(2~5개)·정답·제한시간 수정, 추가/삭제/순서 변경, 텍스트로 한 번에 입력. 저장 즉시 게임에 반영되고 `questions.json`에 기록됩니다.
- **설정**: 행사 이름, 새 참가자 입장 허용/차단, QR 주소 변경, 게임 리셋, 참가자 전원 내보내기

### 문제를 텍스트로 한 번에 입력하는 형식

문제마다 빈 줄로 구분, 첫 줄은 질문, 다음 줄들은 보기, 정답 보기 앞에 `*`, `시간:` 줄은 선택(초):

```
우리 학과 사무실은 몇 층에 있을까?
1층
2층
*3층
4층
시간: 20

O / X : 학과 MT는 매년 봄에 간다.
*O
X
시간: 10
```

## 참고

- 게임 도중 새로 입장한 사람은 관전(탈락) 상태로 들어옵니다. 필요하면 참가자 탭에서 부활시키세요.
- 휴대폰 화면이 꺼지거나 새로고침해도 같은 기기라면 원래 닉네임·생존 상태로 자동 복귀합니다.
- 같은 닉네임이 들어오면 자동으로 뒤에 숫자가 붙습니다 (홍길동 → 홍길동2).
- 참가자 기록은 서버 메모리에만 있어서 서버가 꺼지면 사라집니다.
- 정원은 500명까지로 막아 두었습니다.
