# 실시간 골든벨 (점수제)

QR 찍고 → 아바타·닉네임 정하고 입장 → 부문별로 객관식 문제 풀기 → 맞힐 때마다 점수가 쌓이고, 점수로 순위가 정해집니다. 부문이 끝날 때마다 중간 집계, 마지막에 시상대와 함께 최종 순위를 발표합니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 참가자 | `/` | 휴대폰 (QR로 접속) |
| 무대 화면 | `/screen` | 빔프로젝터·TV |
| 관리자 | `/admin` | 진행자 |

---

## 기존 GitHub 저장소 업데이트하기

1. 이 zip을 풀고 `goldenbell` 폴더를 엽니다.
2. GitHub 저장소 → **Add file → Upload files**
3. `goldenbell` 폴더 **안의 것 전부**(`public` 폴더 + 파일들)를 끌어다 놓습니다. 같은 이름의 파일은 새 것으로 바뀝니다.
4. 목록에 `public/shared.js`(새 파일)가 들어 있는지 확인 → **Commit changes**
5. Render가 자동으로 다시 배포합니다. 2~3분 뒤 상태가 **Deployed**가 되면 끝.

## 진행 순서

1. **관리자 → 문제 편집**: 부문(예: 전공, 넌센스, 상식)을 만들고 문제를 넣습니다. 문제마다 제한시간·배점을 정할 수 있습니다.
2. **관리자 → 디자인**: 행사 이름, 색상, 글꼴을 정하고 **모든 화면에 적용**.
3. **무대 화면**(`/screen`)을 빔프로젝터에 띄움 → 참가자 입장 (아바타와 이름이 화면에 뜸). 오른쪽 아래 **소리 켜기**를 한 번 눌러 두세요.
4. **관리자 → 진행** 탭에서 맨 위 노란 버튼만 차례로 누르면 됩니다.
   - **1부 '전공' 시작** → 무대에 부문 소개 화면
   - **Q1 시작** → 타이머가 끝나면 자동 마감 (또는 **지금 마감**, **+10초**)
   - **정답 공개 · 점수 반영** → 맞힌 사람에게 배점만큼 점수, 무대에 정답·보기별 인원·가장 빨리 맞힌 사람 표시
   - **다음 문제** 반복
   - 부문 마지막 문제 후 **1부 종료 · 중간 집계 발표** → 무대에 누적 순위 Top 10, 휴대폰에 각자 순위
   - **2부 '넌센스' 시작** … 반복
   - 마지막 부문 후 **최종 결과 발표** → 시상대(1·2·3위) + 나머지 순위
5. 그 밖의 버튼
   - **누적 순위 보기 / 이번 부문 순위 보기**: 아무 때나 순위를 띄울 수 있습니다.
   - **원하는 곳으로 이동**: 특정 부문 소개나 특정 문제로 바로 갑니다.
   - **같은 문제 다시 진행**: 그 문제의 점수를 지우고 다시 냅니다 (점수가 두 번 들어가지 않음).
   - **여기서 끝내고 최종 결과 발표**: 시간이 모자랄 때 중간에 끝냅니다.
   - **대기 화면 (잠시 쉬기)**: 쉬는 시간용.

## 점수와 순위

- 맞히면 그 문제의 배점만큼 점수를 얻습니다 (기본 1점, 문제마다 1~100점).
- 탈락은 없습니다. 모두 끝까지 참여합니다. 게임 도중 들어온 사람도 0점에서 시작해 바로 참여합니다.
- **동점 처리** (설정 탭):
  - *빠른 사람 우선* (기본): 맞힌 문제들의 응답 시간 합이 짧은 사람이 위
  - *공동 순위*: 점수가 같으면 같은 순위
- **참가자 휴대폰에 순위 보여 주기**를 끄면 각자 점수만 보이고, 순위는 무대 발표 때만 공개됩니다.
- **참가자 · 점수** 탭에서 부문별 점수를 보고, 점수를 직접 ±1 조정할 수 있습니다 (장기자랑 가산점 등).

## 아바타

입장 화면에서 동물·곤충·하트·기타 중 하나를 고릅니다. 무대의 대기 명단, 순위표, 시상대에 이름과 함께 나옵니다.

## 디자인 바꾸기 (관리자 → 디자인)

- **추천 조합** 5가지 중 하나를 누르거나, 배경·글자·강조색·보기 5색을 직접 고릅니다.
- **제목 글꼴 / 본문 글꼴**을 고릅니다.
- 고르는 동안 관리자 화면에만 미리 보이고, **모든 화면에 적용**을 눌러야 무대·참가자 화면이 바뀝니다.
- 보기 버튼의 글자색(흰색/검정)은 배경색에 맞춰 자동으로 정해집니다.

## 중요: 문제와 디자인을 영구 보관하기

Render 무료 서버는 15분 동안 접속이 없으면 잠들고, 다시 깨어날 때 **관리자 화면에서 저장한 문제·디자인이 GitHub에 올린 파일 상태로 돌아갑니다.** 다 만든 뒤에는 꼭 아래처럼 GitHub에 넣어 두세요.

**문제**
1. 관리자 → 문제 편집 → **저장** → **questions.json 내용 복사**
2. GitHub 저장소에서 `questions.json` 클릭 → 연필(✏️) → 내용 전체 지우고 붙여 넣기 → **Commit changes**

**디자인·행사 이름·순위 규칙**
1. 관리자 → 디자인 → **모든 화면에 적용** → **settings.json 내용 복사**
2. GitHub 저장소 → **Add file → Create new file** → 파일 이름 `settings.json` → 붙여 넣기 → **Commit changes**
   (이미 있으면 그 파일을 열어 연필로 수정)

Commit 하면 Render가 자동으로 다시 배포합니다 (그동안 참가자 기록은 초기화되니 **게임 중에는 하지 마세요**).

그리고 행사 시작 10분 전에 무대 화면을 미리 열어 서버를 깨워 두세요.

## 문제를 텍스트로 한 번에 입력하기

관리자 → 문제 편집 → **텍스트로 한 번에 입력 · 백업**

```
# 전공
곤충의 다리는 모두 몇 개일까?
4개
*6개
8개
시간: 15
점수: 2

# 넌센스
왕이 넘어지면?
*킹콩
왕창
시간: 10
```

- `# 이름` 줄이 새 부문의 시작입니다.
- 문제끼리는 빈 줄로 구분, 첫 줄은 질문, 다음 줄들은 보기, 정답 앞에 `*`
- `시간:`(초), `점수:` 줄은 선택 (없으면 20초, 1점)

## 노트북에서 실행하기 (선택)

```
npm install
npm start
```
관리자 비밀번호 기본값은 `goldenbell` (Render에서는 ADMIN_PASSWORD 값).

## 파일 구성

| 파일 | 내용 |
|---|---|
| `server.js` | 게임 서버 (점수 계산, 순위, 진행) |
| `questions.json` | 부문과 문제 |
| `settings.json` | (선택) 행사 이름·디자인·순위 규칙 |
| `public/index.html` | 참가자 화면 |
| `public/screen.html` | 무대 화면 |
| `public/admin.html` | 관리자 화면 |
| `public/shared.js` | 아바타 목록, 디자인 추천 조합, 글꼴 목록 |
| `public/common.css` | 공통 스타일 |
